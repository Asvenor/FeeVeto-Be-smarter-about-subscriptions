Plain-language overview

Privacy

Your subscription list stays in your browser. SubKiller has no account system, database, advertising, or product analytics.

Information stored by SubKiller

Names, prices, renewal dates, usage choices, importance choices, categories, statuses, and cancellation links you enter are stored using your browser’s local storage. The application does not intentionally transmit that list to SubKiller or its creator.

Backups and deletion

Exporting creates a JSON backup on your device. Importing reads the file you choose in your browser. You can delete individual subscriptions, clear the entire list, or remove this site’s stored data through your browser settings.

Website hosting

This website is hosted by GitHub Pages. GitHub states that it logs visitors’ IP addresses for security purposes. Review GitHub Pages data collection and the GitHub Privacy Statement for details.

External links and feedback

Cancellation links open the service provider you entered. The feedback button opens Google Forms. Information you submit there is handled by Google and the form owner under their applicable practices. Review Google’s Privacy Policy before submitting information.

Changes

If SubKiller later adds accounts, analytics, cloud synchronization, or other data collection, this page should be updated before those features are enabled.
